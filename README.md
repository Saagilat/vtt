# VTT — свой игровой стол на своём сервере

Сервер виртуального игрового стола для D&D-подобных игр по SRD.
Ставится на собственный сервер (VPS за пару сотен рублей в месяц), играет одна компания.
Клиент — программа, которую ставят и мастер, и игроки (D36): страница в браузере не может
запустить утилиту на машине пользователя, а разметчик карт живёт именно там (D35).
Сервер о разметчике не знает — он получает файл и проверяет его. Чужой клиент сможет
подключиться к тому же API, поэтому всё, что говорит сервер, должно быть устойчивым
и описанным.

Сейчас **кода ещё нет** — и это осознанно. Сначала требования, решения и границы проектов;
код появится внутри папок-проектов, каждая из которых собирается и проверяется отдельно.

## Из чего состоит репозиторий

| Папка | Что это | Состояние |
|---|---|---|
| `docs/` | требования, решения, открытые вопросы | 7 документов, решения D01–D36 |
| `contract/` | формат разметки карты: схема, пример, журнал версий | каркас, файлов пока нет |
| `annotator/` | разметчик карт: картинка → `annotation.json`, живёт на машине мастера | каркас, кода пока нет |
| `server/` | игра (443) и панель администратора (8443), Go | каркас, кода пока нет |
| `client/` | стол и карта: клиентская программа | каркас, стек не выбран |

Почему один репозиторий и четыре проекта, а не четыре репозитория и не ветки —
[docs/07-projects.md](docs/07-projects.md), решение D33. Прототип разметки (`tools/`, `schema/`,
`tests/`) снят с рабочего дерева и лежит в истории — коммит `2c504fb`, решение D34.

## Как ведём документы

- **Один вопрос — один документ.** Не сваливаем всё в один длинный файл.
- **Решённое живёт только в `02`.** Нерешённое — только в `03`. В остальных местах — ссылки, а не копии.
  Иначе через месяц три разных версии одного решения.
- **Передумали — не стираем.** Пишем новый пункт и говорим, что он отменяет старый.
- **Эксперимент без цифр не считается проведённым.** Сначала пишем, что и как меряем (`04`),
  потом заполняем таблицу, потом принимаем решение и переносим его в `02`.
- **Документы не врут про состояние кода.** Если файла нет — так и написано, а не «уже готово».
