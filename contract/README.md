# contract — формат разметки карты

Единственное, о чём договариваются разметчик, клиент и сервер: **что именно лежит
в `annotation.json`**.
Описание формата человеческим языком — [FORMAT.md](FORMAT.md),
решение о владельце — D11 в [../docs/02-decisions.md](../docs/02-decisions.md), место проекта
в репозитории — [../docs/07-projects.md](../docs/07-projects.md).

## Что здесь будет лежать

| Файл | Что это |
|---|---|
| `annotation.v1.schema.json` | машинная схема версии 1 (границы, обязательные поля, типы) |
| `annotation.v1.example.json` | пример, на котором проверяются оба валидатора |
| `CHANGELOG.md` | журнал изменений: что добавилось, что сломалось, когда |
| `FORMAT.md` | что именно выдаёт разметка: состав, координаты, сетка, проверка (бывший `docs/05`) |
| `DECISIONS.md` | решения по формату (`CTR-__`): состав, координаты, сетка, повторный прогон |
| `README.md` | этот файл: правила изменения контракта |

## Правила

1. **Владелец формата — сервер** (D11). Разметчик подстраивается под формат, а не наоборот.
2. **Формат версионируется.** Старые разметки читаются после обновления сервера; несовместимое
   изменение — новая версия файла, а не правка старого.
3. **Результат разметки — недоверенный вход, кто бы его ни сделал.** Сервер проверяет файл
   сам: размеры, границы, отсутствие лишнего. Производителем может быть утилита на машине
   мастера, рука мастера с мышкой или будущий чужой инструмент — для сервера это один и тот же
   файл (D35), и поля «кто произвёл» в формате нет. Поэтому валидаторов два (Python
   в разметчике, Go в сервере), и они обязаны одинаково читать один и тот же пример
   и один и тот же набор плохих случаев.
4. **Тишина — не согласие.** Поле, которого нет в схеме, — ошибка, а не «ну ладно».

## Состояние

Кроме `README.md`, `DECISIONS.md` и `FORMAT.md`, папка пуста: схема версии 1 и пример были
частью прототипа и сняты с рабочего дерева (D34). Вернуть в работу:

```sh
git show a675e17:schema/annotation.v1.schema.json > contract/annotation.v1.schema.json
git show a675e17:schema/annotation.v1.example.json > contract/annotation.v1.example.json
git show a675e17:schema/README.md                 # старый README прототипа, только прочитать
```

Возвращать как есть или переписать — решается вместе с разметчиком: у схемы должен появиться
журнал версий, которого у прототипа не было.
