# voice — распознавание речи

Берёт запись голоса и отдаёт текст. Живёт на машине игрока, запускается клиентом и едет
отдельным пакетом `voice`: у кого пакета нет, у того нет ни модели, ни доступа к микрофону.

## Границы

- **Не служба.** Ни порта, ни демона, ни сети: вход — файл, выход — файл, единственный интерфейс —
  командная строка.
- **Микрофон открывает он, а не клиент.** Запись начинается действием человека — кнопкой
  в клиенте, которая запускает `vtt-voice --record`. Клиент не получает доступа к микрофону
  и не содержит кода записи.
- **Звук не уходит с машины.** Распознавание локальное, чужих служб нет, включая встроенные
  в платформу. Запись после распознавания удаляется; текст уходит туда же, куда набранный руками.
- **Модель и рантайм — в пакете.** При первом запуске ничего не скачивается.
- **Карты и правила — не его дело.** Ни картинок, ни сцены, ни прав: только звук → текст.

## Интерфейс

```sh
vtt-voice --file запись.wav --out текст.txt   # распознать готовую запись
vtt-voice --record --out текст.txt            # записать с микрофона и распознать
vtt-voice --version
```

- результат — только файл; прогресс и предупреждения — в stderr, чтобы stdout оставался чистым;
- код возврата: 0 — текст записан, 1 — вход не годится (нет файла, нет микрофона), 2 — внутренняя
  ошибка;
- частичный результат не записывается: либо файл целиком, либо ничего;
- `--file` — и мок для тестов, и способ прогнать настоящую запись без микрофона.

## Чего здесь нет

- нет потока: первая версия распознаёт запись целиком, а не по мере речи;
- нет выбора языка и голосовых команд: один язык, обычный текст;
- нет облака и встроенных служб платформы;
- нет своего формата заметок: текст — это текст, поля «источник» нет.

## Сборка и проверка

Кода пока нет. Реализация — Rust: тот же язык, что у клиента, но отдельный процесс; модель
и рантайм едут в пакете. Снаружи видна только командная строка выше.
